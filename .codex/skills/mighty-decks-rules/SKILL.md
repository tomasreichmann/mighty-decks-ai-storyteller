# Mighty Decks Rules

Use this skill to ground gameplay and content decisions in the current Mighty Decks rules instead of generic RPG assumptions.

## Default Approach

1. Identify whether the decision is core rules, content/adventure structure, or ship combat.
2. Prefer narrative consequence, player agency, tactical tension, and low bookkeeping.
3. Use Outcome cards only when risk and meaningful consequences exist.
4. Represent persistent state with Effects, Stunts, Counters, Assets, Locations, and scene/adventure structure before inventing stats or inventory systems.
5. Keep rules-facing UI text-first unless the task is explicitly a visual board or card prototype.
