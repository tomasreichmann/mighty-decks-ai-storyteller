# Mighty Decks rules

The canonical full rules text is [the Mighty Decks rulebook](mighty-decks-rulebook.md).

The public `/rules` route renders its reader-facing subset as one anchored, printable rulebook page. It deliberately excludes the source document's editorial draft note and instructional-illustration brief, while retaining the numbered core rules, Quick Reference, and Design Philosophy.

Canonical Markdown remains authoritative for all reader-facing prose and examples. Component-composed diagrams are additive enhancements keyed to public section or subsection anchors; they must not replace or shorten the matching Markdown block. The focused visual set covers the Core Action Loop, two valid Fumbles, Actor initiative, Toughness and Counter markers, and Zones and Range.

The `/rules/outcomes`, `/rules/effects`, `/rules/stunts`, and `/rules/assets` tabs remain component-reference pages. `/rules/ship-combat` is a separate prototype reference; it is not part of the canonical core rulebook unless the product owner explicitly makes that rules change.
