# Localization and print roadmap

English is the only supported locale now. Future locales will retain stable IDs, localized display text, output directories, alt text, glyph/RTL support, grammatical composition, completeness validation, and the same renderer. Do not translate text baked into PNGs.

Source-resolution art and geometry are retained for future bleed, safe areas, backs, PDF sheets, and press workflows. Current PNGs are not press-ready.
