# Differences from this application

The package guide authority is the supplied Exiles rulebook. This application continues to use `docs/mighty-decks-rulebook.md` until deliberately migrated.

The fast-session profile caps offered Stunts at one per player per scene and makes solo Stunt choices, persistent upgrades, and expanded storyteller advice central. The current application permits multiple Stunts. These are profile differences, not silent changes to the app's core rules.
