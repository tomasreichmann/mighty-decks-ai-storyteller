# Mighty Decks fast-session storyteller guide

This is the supplied Exiles fast-session, single-player storyteller profile. It is a facilitation aid, not a replacement for the package rulebook or for this application's multiplayer session behavior.

Use the package catalog for card titles and effects, keep choices fiction-first, and treat the one-offered-Stunt-per-player-per-scene rule as profile-specific. See [guide differences](./guide-differences.md).
