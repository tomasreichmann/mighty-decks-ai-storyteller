# Mighty Decks rulebook (package reference)

This package distributes the supplied Exiles rulebook as its main reference. The imported source is retained with the package release process; package components do not change game rules. Use card IDs and catalog text as stable rendering data, while the rulebook remains the authority for play.

## Taken Out

The canonical Effect ID is `taken-out`, titled **Taken Out**. Being Taken Out does not automatically mean dying; recovery follows the fiction and applicable rules.

See [guide provenance](./guide-provenance.md) and [differences from this application](./guide-differences.md).
